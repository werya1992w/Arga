ورود (فقط بار اول)

برای اینکه این صفحه بتونه منو رو تغییر بده، یه «کلید دسترسی» از GitHub لازمه. فقط یک‌بار می‌سازی و روی همین گوشی یا کامپیوتر ذخیره میشه.

  1. وارد github.com بشو (با اکانت صاحب سایت) و برو به Settings ← Developer settings ← Personal access tokens ← Fine-grained tokens ← Generate new token.
  2. اسم: menu — مدت اعتبار (Expiration): بیشترین مقدار.
  3. Repository access ← Only select repositories ← فقط Arga رو انتخاب کن.
  4. Permissions ← Repository permissions ← Contents رو روی Read and write بذار.
  5. دکمهٔ Generate token رو بزن و کلید (که با github_pat_ شروع میشه) رو اینجا بچسبون.

⚠️ این کلید مثل رمز عبوره؛ به کسی نده. اگه گم شد یا لو رفت، از همون صفحهٔ GitHub پاکش کن و یکی جدید بساز.
